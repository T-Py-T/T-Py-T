# Taylor — Platform · SRE · AI systems

**Hire me when you need disposable developer platforms and the systems that run on them** — environments teams can spin up, inspect, steer, and throw away — plus the reliability bar to put ML and agent workloads on them without guessing.

I help companies stop losing weeks to snowflake clusters, opaque agent runs, and “it worked on my laptop” model serving. Twelve-plus years shipping multi-cloud Platform/SRE (EKS/AKS/GKE, GitOps, Terraform, observability, regulated hardening). Public work below is the proof you can clone tonight.

## Problems I take on for your team

- **Serving ML models in production shape.** Paths from training/sandbox to something operable: contracts, manifests, checks, and failure modes you can actually debug — not a notebook left on someone’s desk.
- **Building the platform.** Golden paths, IaC, PR-gated gates, restore drills. Control planes and homelab-grade modules that other engineers can reuse without asking me.
- **Temporary / disposable developer platforms.** Short-lived Kubernetes/GitOps and Nix-defined labs so experiments stay cheap, recoverable, and deletable when they stop earning their keep.
- **Hard Platform / SRE / AI-systems work.** Multi-component orchestration, agent harness evaluation, swarm ops with spend bounds and stop reasons, RL/serving sandboxes — with retained artifacts so claims survive review.
